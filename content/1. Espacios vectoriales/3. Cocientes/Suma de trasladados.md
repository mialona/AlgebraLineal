---
title: Suma de trasladados
---
>[!quote] Teorema
>Sea $S \leq V$ un [[Subespacio vectorial|subespacio]] y $u, v \in V$, se tiene que
>$$
>(v + S) + (w + S) = (v + w) + S.
>$$
>Es decir, el [[Subespacio trasladado|trasladado]] por $v$ más el trasladado por $w$ es el trasladado por $v + w$.

>[!example] Proposición: Suma de trasladados
>La suma de trasladados cumple:
>1. La propiedad asociativa: $((u + S) + (v + S)) + (w + S) = (u + S) + ((v + S) + (w + S))$.
>2. La propiedad conmutativa: $(u + S) + (v + S) = (v + S) + (u + S)$.
>3. Tiene [[Conjunto de elementos|elemento]] neutro: $(0 + S) + (v + S) = v + S$.
>4. Tiene elemento opuesto: $(v + S) + (−v + S) = 0 + S$.
